# Linear baseline ("before")

Generated by `make baseline` from the committed replay set. The run makes no model call and writes the same bytes every time.

## Inputs

- Cases: 600 from `data/replay_2025.parquet`.
- Keyword rules: `config/keywords.toml` version `v1`, committed before any model result existed.
- Truth: the NHTSA component group and the crash/fire/injury/death flag in the same parquet files.
- Groups in truth (10): `adas`, `body_controls`, `electrical_general`, `ev_propulsion`, `infotainment`, `instrumentation`, `lighting`, `power_and_wiring`, `restraints`, `safety_systems`.

## Metrics not available in the linear pipeline

- Quote grounding and citation validity: the baseline quotes no source.
- Issue detection: the baseline has no fleet-level issue agent.
- Recall linking: the baseline links no recalls.

## Workload model

The linear pipeline is modelled with one human touch per case (the person who registers the report and pushes it to the standard test), four fixed steps, zero model cost and zero latency. Those figures come from the synthetic trace in `baseline/pipeline.py`, not from an observed run; they exist so both pipelines feed the same workload function.
