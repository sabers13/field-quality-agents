# Q1 lane report: NHTSA data layer

## What was built

**Fetch and record** (`src/field_quality_agents/data/fetch.py`,
`scripts/fetch_nhtsa.py`)

- Downloads the four required NHTSA ODI flat files in PLAN §5 into the
  git-ignored `data/raw/`, plus the four layout files and the optional
  manufacturer-communications pair found at `tsbs/TSBS_RECEIVED_*.zip`.
- Records URL, sha256, size, `Last-Modified` and download time for each source
  and layout in `data/SNAPSHOT.json`. Optional sources are recorded separately
  and marked `used_in_build: false`.
- Reuses existing archives and hashes them locally unless `--refresh` is
  passed; no network call is made by the offline path.

**Groups** (`data/groups.toml`, `src/field_quality_agents/data/groups.py`)

- Ten electrical/electronic groups built from the snapshot's component-value
  counts. Starting, charging, ignition and wiring are merged into
  `power_and_wiring` because each was thin on its own.
- A component maps to the group with the longest normalised prefix, so
  `ELECTRICAL SYSTEM:ADAS` beats the generic `ELECTRICAL SYSTEM`. Colons and
  whitespace are normalised before matching.
- 278 of 807 distinct component values map to a group (34.5%); the rest are
  non-electrical categories such as `ENGINE` and `POWER TRAIN`.

**Selection and derivation** (`src/field_quality_agents/data/build.py`)

- A complaint is kept only when every component row maps to one group, the
  narrative is at least 80 characters, the PII screen is clean, and make,
  model and year are present.
- Location and identity columns (`CITY`, `STATE`, `VIN`, dealer fields,
  `VEHICLE_OPERATOR`, manufacturer name) never reach a committed file.
- The 2020-2024 knowledge base is stratified by group with a 250-case group
  floor, capped at 40,000. Replay 2025 is 600 cases: a 120-case safety stratum
  plus a stratified general stratum, then sorted by received date. The final
  live set is 150 cases from the last four complete Monday-Sunday weeks
  (`2026-09-28` to `2026-10-25`) and is marked sealed for Q14.
- Weekly fleet counts cover every mapped complaint from 2020 to the snapshot
  edge, counts only.
- Recalls and investigations keep every row with a valid id and open date;
  rows with an unmapped component stay in the parquet with `group = NULL` and
  are excluded from `events.parquet`.
- All parquet is zstd, sorted by a stable key, and written with
  `threads=1` / `preserve_insertion_order=true`.

**PII screen** (`src/field_quality_agents/data/pii.py`)

- VIN, e-mail, phone and street-address patterns. The street-address pattern
  rejects quantities with units ("28,000 miles ... drive") and numbers inside
  thousands separators.
- Counts are reported per pattern and as a union in `data/STATS.md`.

**Statistics** (`src/field_quality_agents/data/stats.py`, `data/STATS.md`)

- Counts per group, safety rates, selection/PII drops, recall and
  investigation mapping rates, event-to-fleet join rate, and file sizes.

## Numbers

- 628,576 complaint rows read, 191,919 single-group complaints.
- 183,151 narratives pass the 80-character floor; 4,831 are dropped by PII,
  935 more by a missing make/model/year; 177,385 eligible.
- Knowledge base 40,000 (3,615 safety-relevant, 9.0%).
- Replay 600 (156 safety-relevant, 26.0%), all received in 2025.
- Final live 150 (16 safety-relevant, 10.7%), sealed.
- Recalls: 247,021 rows / 15,368 campaigns; 118,709 rows and 5,162 campaigns
  map to a group; 114,386 rows written.
- Investigations: 154,455 rows / 5,354 actions; 107,342 rows and 986 actions
  map; 51,762 rows written.
- Events: 46,338 rows (35,965 recall, 10,373 investigation); 12,845 (27.7%)
  join a fleet series key.
- Committed derived data: **8.4 MiB** (8,781,260 bytes), well under the 60 MB
  limit.

## Deviations and shared-code changes

- `fqa data` is implemented in `src/field_quality_agents/cli.py` (Q1 owns the
  data command but the CLI file is shared); Q0's stub test now uses
  `baseline` for the unimplemented path. `make fetch-data` calls
  `fqa data --refresh`.
- Added `duckdb==2.0.0` to `pyproject.toml`/`uv.lock` per
  `docs/NOTES-duckdb.md`.
- Complaints with a missing make, model or year are dropped (935 among long,
  clean narratives; 1,071 across all mapped complaints) because they cannot
  form a fleet key.
- The `component` column is the alphabetically first component of a
  single-group complaint; all components map to the same group.
- Make and model are upper-cased and trimmed; `YEARTXT` 9999/blank becomes
  `NULL`.
- Recall and investigation summaries are stored up to the field maximum
  (6,000 characters); they are public manufacturer filings and are not passed
  through the consumer-narrative PII screen. Only complaint narratives are
  screened.
- `id` in `recalls.parquet` is the NHTSA campaign number and `id` in
  `investigations.parquet` is the NHTSA action number; both repeat across
  product/component rows, as in the source.
- `make all` and `release-check` remain Q8/Q11 concerns; this lane only runs
  the Q1 tests and scans.

  snapshot.
- The optional TSB files are downloaded only to prove availability; if a later
  lane wants manufacturer communications in the knowledge base, that is a
  method change for the captain.
