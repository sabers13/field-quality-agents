### Blockers

- **B1/B2 (leakage).** New `agents/payload.py` is the single place that decides
  what a model may see. It drops `group` and `safety_relevant` from every
  request; intake and analysis both use it. Intake no longer falls back to
  `case.group` for its output and no longer ORs NHTSA's safety flag into the
  prediction. A record run cannot opt back in: `--legacy-recorded-input` is
  refused outside replay mode (`cli.py`, tested). The recorded run's group and
  safety metrics are withheld rather than republished: `Metrics` carries
  `evaluation_labels_in_model_input`, `compute_metrics` leaves those four
  estimates `None` when it is true, and `compare()` explains the blank on the
  dashboard. The recordings cannot answer a request that never included them,
  so Q14 measures them.
- **B3 (intake quotes).** `intake.py::_intake_clues` calls the same
  `verify_quotes` tool as analysis, keeps only verified clues and traces the
  drop; this matters because safety and information-request cases never reach
  analysis. The frozen recorded run keeps its pre-fix extractions; the quote
  metric now re-checks every kept clue and counts the failures.
- **B5 (manifest).** The committed manifest is clean (631 hashes, none from a
  stale export). `make release-check` now runs
  `scripts/results_manifest.py check`, and the check target rebuilds the web app
  and the export first, so a fresh clone with no `dist/` still proves that the
  committed manifest reproduces from the committed results.
- **B6 (release artefacts).** Verified Q10/Q11: README, METHOD, CHANGELOG,
  `project-facts.yml`, the static export and screenshots all exist; `make facts`
  fails when `project-facts.yml` is missing; the export reads the recorded run
  and no fixture number is served any more (see N5).
- **B4 (names).** Open — a captain decision under PLAN §10.2. Q13 states the
  screen's scope in `data/STATS.md` and the README, records the options in
  `reports/DEVIATIONS.md`, and did not rebuild the committed sets (that changes
  the 600-case replay set and needs a new live run) or edit the review's
  evidence.
