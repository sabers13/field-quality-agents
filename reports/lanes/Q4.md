# Q4: model client and record/replay

## What

An OpenAI-compatible chat client for the OpenCode Go endpoint, its cost and
budget configuration, a record/replay store, and a LangChain chat-model wrapper
that both LangGraph and the Q5 desk can use. Every call is offline in tests.

- **`src/field_quality_agents/llm/client.py`**
  - `OpenAIChatClient` posts to
    `https://opencode.ai/inference/go/openai/v1/chat/completions` with the
    DeepSeek V4.1 Flash model id from `docs/NOTES-model.md`.
  - Request shape: `messages`, `tools`, `tool_choice`, `temperature=0`,
    `max_tokens=1024` (config). Responses parse `tool_calls[*].function.arguments`
    as JSON into `ToolCall.arguments` dicts.
  - Retries only transport errors and HTTP 429. A 429 honours `Retry-After`
    (seconds or an HTTP date) inside a bounded cap, else uses bounded
    exponential backoff. 403 and any abuse/policy text stop immediately.
  - A bad answer raises `BadAnswerError` on the first response and is never
    retried: non-JSON bodies, missing choices/message/finish reason, empty
    answers, malformed or unknown tool calls, and non-string arguments.
  - `403`, an error body with a policy phrase, or a policy phrase in the answer
    raises `PolicyStopError`, which appends `reports/STOP.md` before the caller
    sees the exception (PLAN §10 rule 3). 400/401/5xx otherwise raise
    `TransportError`; none are retried.
  - Pacing is 2 concurrent requests and 30 starts in any 60 seconds, shared by
    retries; the semaphore is released while waiting to retry. `latency_ms`
    measures the request, not the pacing wait.
  - Own `User-Agent: field-quality-agents/0.1` and a stable
    `x-opencode-session` header, as the endpoint asks.
  - Cost: the gateway's `usage.opencode.list_cost` when present (PLAN §9),
    else a non-zero `usage.cost`, else tokens × `config/prices.toml`. The
    charged cost, list cost and Go allowance are all kept in `Usage`.
- **`src/field_quality_agents/llm/credentials.py`**
  - Order: the file named by `FQA_ENV_FILE` (default
    `~/.config/field-quality-agents/upstream.env`), then `.env`.
  - Accepts `FQA_API_KEY`, `OPENCODE_API_KEY`, `OPENCODE_GO_API_KEY`,
    `OPENAI_API_KEY`, `DEEPSEEK_API_KEY`, `API_KEY`; a single-assignment file
    with another name is accepted when unambiguous.
  - `SecretKey.__repr__`/`__str__` are redacted; only `reveal()` returns the
    value and only the HTTP client calls it to build the auth header. No
    module prints, logs or serialises it. The client loads the key lazily on
    the first request.
- **`src/field_quality_agents/llm/recorder.py`**
  - `RecordReplayStore` keys on
    `sha256(model + prompt version + canonical messages + tools)` with sorted
    JSON. Recordings are `recordings/<first two hex>/<key>.json`; a flat
    `<key>.json` is accepted on read. `put` is idempotent and refuses in replay
    mode.
  - `RecordReplayChatClient` reads the store first; on `ReplayMissError` in
    record mode it calls the live client and stores the answer; in replay mode
    it propagates the miss without a network call.
- **`src/field_quality_agents/llm/langchain_model.py`**
  - `LangChainChatModel(BaseChatModel)` implements `_generate`, `_llm_type`,
    `bind_tools` (returning a copy with OpenAI tool specs) and Q5's
    `complete()` protocol (`ModelTurn` with text, tokens, cost, duration).
  - `AIMessage.tool_calls`, `usage_metadata` and `response_metadata` carry the
    parsed calls and usage. Both `invoke` and `complete` go through the same
    record/replay path.
- **`src/field_quality_agents/llm/models.py`**: the frozen `ToolCall`, `Usage`,
  `ChatResponse` shapes plus deterministic recording serialisation.
- **`src/field_quality_agents/llm/errors.py`**: `TransportError`,
  `RateLimitError(retry_after)`, `PolicyStopError`, `BadAnswerError`,
  `ReplayMissError`.
- **`config/prices.toml`**: off-peak USD 0.15/0.60/0.003 per million for
  input/output/cached input, peak multiplier 2.0 on the UTC windows from the
  notes, plus a `default` model fallback.
- **`config/budget.toml`**: 12 steps, 40k tokens, 2 concurrent, 30/minute,
  retry and request defaults.

## How tested

`tests/llm/` (45 tests), all with `httpx.MockTransport`; the session-wide
socket guard stays on and no real key is read:

- `test_client.py`: success with a tool call and request-shape/header asserts;
  token-priced cost and peak multiplier; gateway list cost/allowance; 429 with
  `Retry-After` then success; 429 exhaustion; transport-error retry and
  exhaustion; 403 writes `STOP.md` and is not retried; bad answers (malformed
  arguments, empty answer, no choices, unknown tool, non-JSON body) call once;
  policy text in an answer and in an error body writes `STOP.md`; 5xx is a
  transport error; `Retry-After` HTTP dates; 30/minute pacing; two-concurrent
  semaphore; latency; safe `repr`.

  touched; replay miss raises with no file; key stability across dict order and
  sensitivity to prompt version; read-only replay store; serialisation

  `FQA_ENV_FILE` honoured, `.env` fallback, redaction, single-assignment file,
  missing key without leaking contents, price file values, peak/weekend rules,

## Deviations and shared-file changes

- **`pyproject.toml` + `uv.lock`**: added `httpx>=0.28,<1` and
  `langchain-core>=1.7,<2` as explicit dependencies. Both were already present
  transitively through `langgraph`/`pytest`, but Q4 imports them directly, so
  they belong in the project dependencies. This is the only shared-file change.
- Cost recorded as `cost_usd` prefers the gateway list cost when present, per
  PLAN §9; `allowance_usd` and `list_cost_usd` keep the Go accounting visible.
- The policy scanner uses specific phrases ("usage policy", "account warning",
  "request blocked", "abuse policy", ...) rather than the bare word "abuse", so
  a complaint narrative quoted in a model answer cannot stop a real run by
  accident.
- Config loaders fall back to the committed defaults when `config/*.toml` is
  absent, so the client works when the process working directory is not the
  repository root. The committed files remain the source of truth.
- No streaming: not required by the brief or `docs/INTERFACES.md`.
